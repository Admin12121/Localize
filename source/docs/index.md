The dated [upgrade design](superpowers/specs/2026-10-26-web-bridge-upgrade-design.md) records the agreed direction. Current user-facing behavior and limits are documented in these guides and the tool catalog; a design record is not proof that a capability is enabled.

These text guides travel with the portable source/setup package. Large repository illustrations are intentionally excluded. Automatic ChatGPT event prompts are not enabled; saved tasks resume on the next prompt or through an explicitly started optional local agent.
