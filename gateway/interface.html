Optional capabilities

Isolated commands

Install Docker with Linux containers and prepare an image locally:

docker pull python:3.12-alpine

Other supported images: node:24-alpine and alpine:3.21. Images are never pulled silently by model requests.

Chromium browser tools

python -m pip install playwright
python -m playwright install chromium

On macOS/Linux, use python3 if python is unavailable. Linux may need browser OS dependencies and a working Chromium sandbox.
